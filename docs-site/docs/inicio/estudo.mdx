<Decision adr="ADR 003" href="/decisoes/outbox">

  tentar a publicação novamente após uma interrupção.
</Decision>

<Comparison rows={[
  {option: 'Publicar diretamente no Kafka', tradeoff: 'A gravação no banco e o envio ao broker continuam em sistemas distintos. A operação teria que reconciliar falhas entre os dois.'},

## Exemplos por linguagem

<Tabs groupId="linguagem" defaultValue="sql">
<TabItem value="sql" label="SQL">

```sql
SELECT count(*) FROM boleto_outbox WHERE published_at IS NULL;
```

</TabItem>
<TabItem value="java" label="Java">

O consumidor chama `BoletoEventConsumer.receive(String message)`. O
evento recebido é representado por `BoletoEvent` e o recibo usa
`INSERT ... ON CONFLICT DO NOTHING`.

</TabItem>
<TabItem value="yaml" label="YAML">

Trecho da configuração do consumidor Kafka.

```yaml
spring:
  kafka:
    listener:
      ack-mode: record
```

</TabItem>
